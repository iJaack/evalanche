Why v1.14.0 matters

01 Official Avalanche SDK by default 
Native X/P/C operations now run on the official @avalanche-sdk/client. The legacy Core wallet and vulnerable HPKE dependency trees are gone from fresh installs, and clean consumer audits report zero production vulnerabilities.
02 Avalanche L1 discovery 
Live mainnet and Fuji L1 catalog lookup, RPC chain ID verification, and native-token preservation, exposed as public SDK and MCP helpers. L1 wallets are EVM-only.
03 Leaner, hardened runtime 
dYdX support is removed (Hyperliquid remains for perpetuals). X/P/C routing, offline signing, network switching and HTTP limits are hardened. Requires Node.js 20 or newer.
